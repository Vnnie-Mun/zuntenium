# Zuntenium VS Code Extension

This extension integrates the Zuntenium Hybrid Quantum Simulation Framework into Visual Studio Code.

## Features

* Run `.qasm` circuits directly from VS Code.
* View Zuntenium system information and backend status.
* Configure custom Python paths and default simulators.

## Usage

1. Open a `.qasm` file.
2. Right-click in the editor and select **Zuntenium: Run QASM Circuit**.
3. View the results in the Output panel.
